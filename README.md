# Sicheng Qu — Academic Homepage

A lightweight, single-page academic homepage for Sicheng Qu. It is plain HTML, CSS, and JavaScript, so it can be opened locally or deployed directly to GitHub Pages.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive layout and light/dark themes
- `script.js` — English/Chinese switch and theme toggle
- `assets/cvimg-000.png` — portrait extracted from the CV

## Deploy

Create a GitHub repository named `YOUR-USERNAME.github.io`, copy these files into it, and enable GitHub Pages from the repository settings. Before publishing, replace the portrait if you prefer a different public version and add any personal links you want to show.
